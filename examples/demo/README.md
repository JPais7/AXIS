# AXIS synthetic demonstration

This demonstration contains three entirely synthetic cohort summaries. It has
no participant-level, biological or clinical data and supports no disease
claim. Its purpose is to verify the public AXIS installation and demonstrate:

- SHA-256 input integrity;
- participants counted as the unit of evidence;
- two compatible primary cohorts;
- a broader third cohort retained as sensitivity evidence;
- deterministic random-effects synthesis;
- machine-readable checks and reports.

From the repository root, run:

```shell
axis demo
```

Outputs are written to `demo-output/`. A successful run reports that all nine
checks passed. Delete that output directory at any time; it is regenerated by
the command.

The numbers are deliberately synthetic. Use `axis reproduce ddx24-study` only
when the separately distributed frozen DDX24 inputs are available.
