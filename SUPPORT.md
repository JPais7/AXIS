# Support

Use the [AXIS issue tracker](https://github.com/JPais7/AXIS/issues):

- installation or execution problem: include operating system, Python version,
  AXIS version, command and complete error message;
- scientific-method question: include the research question, study accessions,
  tissue, assay, comparison and intended evidence role;
- suspected security or privacy problem: follow `SECURITY.md` and do not post
  sensitive details publicly.

AXIS is provided without clinical support. Outputs require review by qualified
researchers and must not be used as diagnosis, treatment advice or evidence of
therapeutic efficacy.
