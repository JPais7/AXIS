# Security and responsible disclosure

Do not place access tokens, credentials, identifiable participant information
or controlled-access data in AXIS issues, examples or repositories.

Do not disclose exploitable or privacy-sensitive details in a public issue.
Send a private report to `joaopais2000@hotmail.com` with the subject
`AXIS security report`. Include only the minimum information required to
reproduce the problem and do not attach participant data.

Supported security updates currently apply to the latest development version.
AXIS is research software, not a medical device or clinical decision system.
