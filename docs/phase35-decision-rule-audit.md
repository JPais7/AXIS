## DECISION-GAP-001 (v1)

* **Description:** Engagement uncertainty when biochemical activity and a compound phenotype are supported but direct cellular engagement is not.
* **Required inputs / evidence dependencies:** edges.biochemical, edges.engagement, compound_phenotype_ids
* **Condition:** biochemical edge supported AND >=1 supported compound phenotype; status from the engagement edge (supported/contradicted -> resolved for current decision, mixed -> partially resolved, otherwise open)
* **Output:** target_engagement uncertainty (decision_material)
* **Rationale:** A phenotype is not engagement; the bridge is unobserved, not refuted.
* **Failure behaviour:** Not fired without both inputs; never infers engagement from phenotype.
* **Tests:** test_decision.py::test_uncertainty_missing_engagement_conflict_selectivity_context; acceptance::cf1, cf3, cf6

## DECISION-GAP-002 (v1)

* **Description:** Raise engagement to decision_blocking while selectivity is unresolved, because an off-target explanation then cannot be excluded.
* **Required inputs / evidence dependencies:** selectivity.comparable, uncertainty target_engagement
* **Condition:** GAP-001 open AND no directly comparable selectivity comparison
* **Output:** target_engagement decision_blocking
* **Rationale:** Without engagement or comparable selectivity the compound phenotype cannot be attributed to the target and the strategy decision cannot be taken.
* **Failure behaviour:** With comparable selectivity the uncertainty stays decision_material.
* **Tests:** acceptance::cf6, cf7, cf8

## DECISION-TRANS-001 (v1)

* **Description:** Assay-translation uncertainty when biochemical activity is supported and no cellular phenotype or engagement is supported.
* **Required inputs / evidence dependencies:** edges.biochemical, edges.engagement, compound_phenotype_ids
* **Condition:** biochemical edge supported AND no supported compound phenotype AND engagement not supported
* **Output:** assay_translation uncertainty (decision_blocking)
* **Rationale:** Biochemical activity alone says nothing about activity in cells.
* **Failure behaviour:** Not fired when any phenotype or engagement exists.
* **Tests:** acceptance::cf4

## DECISION-DEP-001 (v1)

* **Description:** Dependency uncertainty when genetic dependency is supported but compound dependency is uncertain or not assessed.
* **Required inputs / evidence dependencies:** genetic_dependency_ids, compound_dependency_uncertain_ids
* **Condition:** compound phenotype AND (genetic dependency supported OR compound dependency uncertain/not assessed)
* **Output:** target_dependency uncertainty (decision_material)
* **Rationale:** Genetic dependency does not transfer to a compound without a matched chemical-genetic comparison.
* **Failure behaviour:** Resolved only by supported compound dependency with none uncertain.
* **Tests:** test_decision.py::test_resolved_gap_changes_status_and_critical; acceptance::cf1

## DECISION-SEL-001 (v1)

* **Description:** Selectivity uncertainty when no selectivity comparison is directly comparable; quantity of incompatible data never counts as resolution.
* **Required inputs / evidence dependencies:** selectivity
* **Condition:** compound phenotype exists; resolved only if >=1 comparable AND none unresolved
* **Output:** selectivity uncertainty (decision_material, indirectly_testable)
* **Rationale:** A cellular experiment alone cannot resolve selectivity; it needs a comparable biochemical panel.
* **Failure behaviour:** Raw measurement counts never resolve it; 'Not assessed' and 'Not directly comparable' are reported separately.
* **Tests:** acceptance::cf7, cf8

## DECISION-CTX-001 (v1)

* **Description:** Genetic-context uncertainty when the target allotype/genotype is unreported in every experiment or an experiment lacks the disease-relevant context.
* **Required inputs / evidence dependencies:** contexts
* **Condition:** contexts present; open if target allotype unreported in every experiment OR any experiment lacks the disease-relevant context
* **Output:** genetic_context uncertainty (decision_material)
* **Rationale:** Target biology is context sensitive; contexts are not interchangeable.
* **Failure behaviour:** Resolved only when allotype reported and no unmatched context.
* **Tests:** test_decision.py::test_uncertainty_missing_engagement_conflict_selectivity_context; acceptance::cf10

## DECISION-REPRO-001 (v1)

* **Description:** Reproducibility uncertainty when sources report opposite directions for the same genetic endpoint.
* **Required inputs / evidence dependencies:** source_disagreements
* **Condition:** genetic readouts with the same endpoint from >1 source with both increase and decrease
* **Output:** reproducibility uncertainty (decision_material)
* **Rationale:** Opposite directions in distinct systems are source disagreement, not noise to average away.
* **Failure behaviour:** Not fired for a single source or a single direction.
* **Tests:** test_decision.py::test_uncertainty_missing_engagement_conflict_selectivity_context; acceptance::cf10

## DECISION-EXPL-001 (v1)

## DECISION-CRIT-001 (v1)

* **Required inputs / evidence dependencies:** uncertainties, explanations, candidates
* **Condition:** eligible = open/partially resolved AND testable; lexicographic over relevance, viable explanations affected, resolvability, candidate available, distinct next actions

## DECISION-EXP-001 (v1)

* **Description:** Discrimination: pairs of viable explanations moved in opposite directions by at least one scenario.
* **Required inputs / evidence dependencies:** outcome interpretations
* **Condition:** a scenario strengthens one viable explanation and weakens another
* **Output:** separated pair list; low_discrimination flag
* **Rationale:** An experiment is discriminating only if explanations predict different outcomes.

* **Tests:** test_decision.py::test_discrimination_unit

## DECISION-RESULT-001 (v1)

* **Description:** Apply eligible experimental-result contributions to their own evidence edge and scope only; never cascade to another edge or generalize to another scope or context.
* **Required inputs / evidence dependencies:** contributions (eligible under the review policy)
* **Condition:** an eligible contribution folds into its own edge and scope only
* **Output:** scoped edge states; project edge aggregate
* **Rationale:** Each edge requires its own evidence; a result is bound to its scope.
* **Failure behaviour:** No cascade to other edges; no generalization to other scopes or contexts.
* **Tests:** results_loop::test_edge_must_be_measured_and_does_not_cascade, test_happy_path_*

## DECISION-RESULT-002 (v1)

* **Description:** Roll engagement up over the phenotype-producing scopes: complete only when every required scope is decided; otherwise partial or open.
* **Required inputs / evidence dependencies:** required scopes, scoped engagement states
* **Condition:** engagement rolled up over required scopes: complete only if all decided
* **Output:** engagement rollup and uncertainty status
* **Rationale:** Target-level resolution is distinct from compound-level resolution.
* **Failure behaviour:** A result for one scope never decides another; project state stays 'incomplete'.
* **Tests:** results_loop::test_compound_isolation_and_unresolved_identity, test_complete_resolution_*

## DECISION-RESULT-003 (v1)

## DECISION-REPRO-002 (v1)

* **Description:** Opposite eligible results for the same edge and scope yield a mixed scope state and a reproducibility uncertainty; both are preserved.
* **Required inputs / evidence dependencies:** scoped edges
* **Condition:** eligible contributions for the same edge and scope disagree (supported and contradicted)
* **Output:** reproducibility uncertainty
* **Rationale:** Contradiction is data; results are never averaged into consensus.
* **Failure behaviour:** Scope state is 'mixed'; both results stay; reproducibility uncertainty raised.
* **Tests:** results_loop::test_every_phase_36_rule_fired_in_this_module

## DECISION-REVIEW-001 (v1)

* **Description:** Scenario→explanation mappings and candidate designs enter a decision only if their review state is allowed by the review mode; rejected, conflicting and needs-revision are always excluded.
* **Required inputs / evidence dependencies:** review states, review mode
* **Condition:** mapping or design review state not allowed by the review mode is excluded
* **Output:** filtered mappings and candidate set; review dependencies
* **Rationale:** A rejected mapping must not silently stay active.
* **Failure behaviour:** Rejected/conflict/needs-revision always excluded; pending only in exploratory mode.
* **Tests:** results_loop::test_scenario_mapping_review_controls_ranking, test_rejected_mapping_*
