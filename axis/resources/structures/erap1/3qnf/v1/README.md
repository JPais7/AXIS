The deterministic AXIS transformation is provider-segment-projection v1.
It verifies provider anchors against the pinned sequence, preserves label/author
numbering and insertion codes, then projects correspondence; it does not run
sequence alignment. Unanchored/ambiguous/unequal-span mappings fail closed.
Each persisted chain has transformation parameters, software/parser versions,
input checksums, output mapping checksum and descriptive coverage.
Golden output checksums are tested against the pinned Phase 3.1 identity.

Selection favoured explicit human Q9NZ08 cross-reference, straightforward sequence
correspondence, documented tags and useful chain-specific missing coordinates.

bound molecule. Neither entry establishes therapeutic validity.
